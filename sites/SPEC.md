# Сайт Primeegg Distribution SL — техзадание на один вариант

Прочитай `../BRIEF.md`. Твой концепт — `PE-SS.NN`. Источники фирменного стиля:
- `logobooks/<код>/data.json` + `data.es.json` / `data.uk.json` — палитра, шрифты, история знака;
- `brandbooks/<код>/brand.es.json` / `brand.uk.json` — платформа, голос, слоганы, тексты `web.*`, `products.*`, `headlines_es`, контакты;
- графика: `python3 tools/export_assets.py <код> sites/<код>/assets` — логотипы, паттерн, мокапы-сцены (упаковка, HoReCa, порошок, логистика, униформа, пиктограммы) в SVG;
- посмотри готовые брендбуки `brandbooks/<код>/<код>_Brandbook_ES.html` — сайт должен быть узнаваемо этим брендом.

## Что сделать
Статический сайт без фреймворков и сборщиков: `sites/<код>/index.html` (испанский, основной) и `sites/<код>/uk.html` (украинский). Один HTML-файл на язык, весь CSS и JS — внутри файла. Графика из `assets/` вставляется **инлайном** (SVG прямо в разметку — иначе не загрузятся шрифты в логотипах). Внешние ресурсы — только Google Fonts.

### Разделы главной (одностраничник с якорной навигацией)
1. **Шапка**: логотип, меню (Productos / HoReCa / Distribución / Calidad / Nosotros / Contacto), переключатель **ES | UA** (ссылки index.html ↔ uk.html, `hreflang`), кнопка «Solicitar presupuesto». На телефоне — бургер-меню.
2. **Hero** с главным сообщением бренда (`web.hero_title`, `web.hero_text`, `web.cta`), выразительная векторная графика в стиле бренда.
3. **Productos**: яйца свежие (категории/размеры S–XL, белые/коричневые, camperas/ecológicos), яичный порошок (цельный, белок, желток), «próximamente»: жидкий меланж и др. Карточки со спецификацией и сценами упаковки.
4. **Para hostelería (HoReCa)**: формат лотков 30 шт., регулярные поставки, персональный менеджер, график; мокап HoReCa.
5. **Distribución / logística**: стилизованная SVG-карта Испании с зонами доставки 24/48 h, холодовая цепь, минимальный заказ; мокап фургона.
6. **Calidad y trazabilidad**: код маркировки яйца (как читать «1ES28001»), контроль партий. Сертификаты — нейтральными плашками-заглушками (никаких выдуманных реальных номеров).
7. **Cómo trabajamos**: 3–4 шага заказа.
8. **Formulario B2B «Solicitar presupuesto»**: тип клиента (mayorista / HoReCa / retail / industria), компания, CIF, контакт, e-mail, телефон, провинция, продукты (чекбоксы), объём в неделю, комментарий, согласие RGPD. Валидация в браузере, `submit` обрабатывается в JS с `preventDefault()` и показом сообщения об успехе на странице (никуда не отправлять).
9. **Nosotros** (миссия/ценности из brand.json) и **FAQ** (5–6 вопросов, аккордеон на `<details>`).
10. **Подвал**: контакты из `contacts`, юр. название Primeegg Distribution SL, ссылки-заглушки Aviso legal / Privacidad / Cookies, переключатель языка.

### Дизайн
- Каждый из 5 сайтов должен быть **заметно другим по композиции и характеру**, а не перекраской одного шаблона: структура hero, сетки, ритм, типографика, работа с паттерном и цветом выводятся из характера бренда (премиум — воздух и редакционная вёрстка; B2B — плотная информационная подача и цифры; Средиземноморье — тёплые плоскости и плитка; ретейл — крупные формы и игривость; эко — спокойствие, линии, много «природного» воздуха).
- Если доступен skill `impeccable` — загрузи его и следуй его рекомендациям по качеству фронтенда.
- Шрифты: из логобука. **В uk.html заголовки и текст — гарнитурами с кириллицей** (см. `cyr()` в `tools/brandkit.py`: Fraunces→Playfair Display, Baloo 2/Fredoka/Quicksand→Nunito, Josefin/Archivo→Montserrat, Space Grotesk/Syne/Outfit→Manrope, DM Serif→Playfair Display, Bebas→Oswald; Lora, Montserrat, Manrope, Inter, Nunito, Oswald, Playfair, Cormorant — уже с кириллицей).
- Адаптив: 360–1920 px, без горизонтального скролла, бургер-меню на мобильных. Доступность: семантические теги, alt/aria-label для графики, видимый фокус, контраст AA, `prefers-reduced-motion`.
- Анимации — сдержанные (одно продуманное появление hero, ховеры). Никаких тяжёлых библиотек.
- Без фото-стоков: только векторная графика, паттерны, мокапы из assets, CSS.

### Тексты
- ES — естественный испанский Испании, голос бренда из `tone`. UA — литературный украинский, тот же смысл и голос (переведи `web.*`, `headlines_es` и прочие испанские поля сам). Продукция на мокапах остаётся на испанском — это нормально.
- Контакты условные, из `contacts`.

## Проверка
- Скриншоты в headless Chrome (рабочая папка — `$TMPDIR/site-<код>/`):
  `"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --headless=new --disable-gpu --hide-scrollbars --window-size=1440,6000 --virtual-time-budget=15000 --screenshot=<png> file://<абсолютный путь к html>` и то же с `--window-size=390,9000`. Обе языковые версии. Открывай PNG через Read, режь длинные скриншоты на части (PIL доступен) и правь всё, что налезает, обрезается или выглядит неряшливо.
- Нет горизонтального скролла: проверь `document.documentElement.scrollWidth <= innerWidth` через `--dump-dom` со скриптом или визуально на 390 px.
- `xmllint --html --noout` не обязателен, но HTML должен быть валидным по смыслу (закрытые теги, уникальные id).
- Не трогай файлы вне `sites/<код>/`, не делай git-коммиты.
