# Логобук: компоненты, которые готовит дизайнер

Прочитай `../BRIEF.md` и `../logos/SPEC.md` (правила SVG и разрешённые шрифты действуют и здесь).
Страницы логобука (HTML и SVG для Figma) собирает скрипт из твоих компонентов — тебе нужно сделать только компоненты и `data.json`.

Папка: `logobooks/PE-SS.NN/` (SS — номер стиля, NN — номер логотипа; исходник: `logos/<SS-style>/NN.svg`, его описание — в `logos/<SS-style>/meta.json`).

## SVG-компоненты (все без фона, без width/height, только viewBox)
| файл | viewBox | что внутри |
|---|---|---|
| `primary.svg` | `0 0 400 300` | Основная версия. Возьми исходник, доведи до чистового качества (выравнивание, оптические поправки, ровные отступы, логотип по центру, поля ≥ 24). Идею не меняй. |
| `horizontal.svg` | `0 0 640 200` | Горизонтальная версия: знак слева, надпись справа, всё по центру по вертикали. Поля ≥ 16. |
| `vertical.svg` | `0 0 400 400` | Вертикальная: знак сверху, надпись под ним. |
| `mark.svg` | `0 0 200 200` | Только знак (иконка), занимает ~150–170px, по центру. Если логотип — чистый wordmark или эмблема, сделай производный знак (монограмма P, элемент-яйцо из логотипа), который узнаваемо из него вытекает. Читается в 16px. |
| `wordmark.svg` | `0 0 640 160` | Только название (+ дескриптор по желанию), без знака. |
| `mono.svg` | `0 0 400 300` | Одноцветная версия основной: ВСЕ заливки/обводки — строго `currentColor`, никаких других цветов, никакого белого. Просветы (желток внутри яйца и т.п.) делай вырезом: `fill-rule="evenodd"` или `<mask>`. Должна оставаться узнаваемой и читаемой. Скрипт перекрасит её в чёрный, белый, фирменный. |
| `inverse.svg` | `0 0 400 300` | Цветная версия для тёмного фона `dark_bg` из data.json (цвета подобраны под тёмный фон, светлый текст). |

Шрифты в компонентах — те же, что в исходнике. Текст по дуге (`textPath`) и `textLength` разрешены (скрипт запечёт их для Figma).
Все компоненты должны быть визуально одной системой: одинаковые пропорции знака, цвета, шрифты.

## data.json
```json
{
  "code": "PE-01.05",
  "name": "Средиземноморский горизонт",
  "name_en": "Mediterranean Horizon",
  "tagline": "одна короткая фраза-позиционирование на русском",
  "story": ["абзац 1: идея знака", "абзац 2: почему это работает для Primeegg (B2B, HoReCa, ретейл)"],
  "elements": [{"element": "Яйцо", "meaning": "продукт, форма бренда"}, ... 3–4 штуки],
  "palette": [
    {"role": "Основной", "name": "Средиземноморская лазурь", "hex": "#1D5FA8", "rgb": "29 95 168", "cmyk": "90 55 0 0", "pantone": "≈ 2935 C"},
    ... 3–5 цветов: основные, акцентный, нейтральные (тёмный текст и светлый фон)
  ],
  "dark_bg": "#0F2A4A",
  "brand_bg": "#1D5FA8",
  "fonts": [
    {"role": "Логотип", "family": "Inter", "weights": "700", "note": "использован в надписи логотипа"},
    {"role": "Заголовки", "family": "...", "weights": "...", "note": "..."},
    {"role": "Текст", "family": "...", "weights": "400, 500", "note": "..."}
  ],
  "clear_space": {"unit_name": "высота желтка (x)", "unit": 22},
  "min_size": {"print_mm": 20, "screen_px": 80, "mark_px": 16}
}
```
- `clear_space.unit` — размер модуля x в единицах primary.svg (охранное поле = 1x вокруг логотипа). Выбери осмысленный элемент логотипа (высота желтка, высота строчной буквы и т.п.).
- CMYK и Pantone — профессиональная приблизительная конверсия, Pantone помечай «≈».
- Шрифты — только из списка `logos/SPEC.md`. Для заголовков/текста фирменного стиля подбери пару, сочетающуюся с логотипом.
- Тексты на русском, грамотные, профессиональные, без воды.

## Проверка
- `xmllint --noout logobooks/PE-SS.NN/*.svg`, `python3 -c "import json;json.load(open('logobooks/PE-SS.NN/data.json'))"`.
- Визуально проверь рендер с настоящими шрифтами в headless Chrome:
  `"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --headless=new --disable-gpu --virtual-time-budget=10000 --window-size=W,H --screenshot=<scratchpad>/x.png file://<html>` — сделай во временной папке (`$TMPDIR` или scratchpad) HTML, который подключает нужные Google Fonts (`<link href="https://fonts.googleapis.com/css2?family=...&display=block" rel="stylesheet">`) и показывает все 7 компонентов (mono — с `color:#000`, inverse — на `dark_bg`), открой скриншот через Read и исправь всё, что налезает, вылезает или выглядит неряшливо. Не используй встроенный браузер.
- Не трогай файлы вне своей папки, не делай git-коммиты.
