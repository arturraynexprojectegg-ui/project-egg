# Мокапы брендированной продукции

Каждый мокап — сцена для одного слайда брендбука, нарисованная векторно (SVG) и автоматически оформляемая фирменным стилем любого из 13 концептов через `BrandKit` (см. `tools/brandkit.py` — прочитай докстринг, там весь API).

## Контракт
Файл `tools/mockups/<scene>.py`:
```python
TITLE = "Упаковка для розницы"           # заголовок слайда (русский)
CAPTION = "Коробка на 6 и 12 яиц, ..."     # подпись под сценой, 1 предложение (русский)
def render(k, W=1680, H=700) -> str:       # SVG-фрагмент в координатах 0..W × 0..H, без <svg>, без фона сцены
    ...
```
- Сцена рисуется на светлом фоне слайда (#FBFAF7), её фон прозрачный. Внутри — 1–4 предмета, скомпонованных как профессиональная презентация (как фото-мокапы на Behance, но в чистом векторе): ровные отступы, единый свет сверху-слева, мягкие тени (полупрозрачные эллипсы/градиенты, **без filter**).
- Стиль предметов — аккуратный плоский/полуобъёмный вектор: фронтальные виды, вид сверху или простая изометрия (через skew/матрицы). Реалистичные пропорции предметов, детали (клапаны коробки, ячейки лотка, шов мешка, колёса и окна фургона, швы фартука).
- **Все цвета и шрифты — только из `k`**: `k.primary, k.accent, k.dark, k.light, k.ink, k.brand_bg, k.paper, k.palette`, `k.head_font/k.text_font/k.logo_font`, `k.on(bg)` для цвета текста. Нейтральные материалы (крафт-картон #C9A57A, гофрокартон, белая скорлупа #F4EEE3, коричневая скорлупа #D9A877, металл, шины #2A2A2A, стекло) — фиксированными цветами можно.
- Логотип — только через `k.logo(key, x, y, w, h, color=None)`: на светлом — `primary/horizontal/vertical`, на тёмном или фирменном — `inverse` или `mono` с `color=k.on(bg)`, на крафте/штампе — `mono` с `color=k.ink` или `k.dark`. Знак — `mark`.
- Паттерн — `k.pattern_rect(...)` (у части концептов pattern.svg может ещё не быть — тогда метод просто ничего не рисует; сцена должна хорошо выглядеть и без него).
- Тексты — из `k.t("products.carton.title", "Huevos frescos")` и т.п. (ключи см. `brandbooks/SPEC.md`), с разумными испанскими значениями по умолчанию. Мелкий служебный текст (вес, срок годности, код фермы, штрихкод) рисуй правдоподобно. Испанский язык на продукции.
- Ограничения SVG как в `logos/SPEC.md`: без filter, image, foreignObject, style, script. Градиенты и clipPath — с id из `k.uid()`. Текст — обычный `<text>` (textPath можно).
- Никаких внешних зависимостей, только стандартная библиотека Python.
- Сцена должна выглядеть хорошо у ВСЕХ концептов: светлые и тёмные палитры, горизонтальные и круглые логотипы (эмблемы), разные шрифты. Резервируй под логотип боксы с запасом и вписывай через `k.logo` — он сам сохраняет пропорции.

## Проверка
`python3 tools/preview_mockup.py <scene> <out.png> [PE-коды...]` — рендерит сцену для нескольких концептов (по умолчанию 4 разных) с настоящими Google Fonts. Открой PNG через Read и доводи до уровня профессионального брендбука. Проверь минимум 6 разных концептов (все коды: `ls logobooks`).
Временные файлы — в своей подпапке `$TMPDIR/<scene>/`. Не трогай чужие файлы, не делай git-коммиты.
